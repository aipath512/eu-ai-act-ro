# Exemple de linkuri UTM gata de folosit — eu-ai-act.ro

Copiază linkul complet (nu doar `eu-ai-act.ro`) în postare/email/material.

```
https://eu-ai-act.ro/?utm_source=linkedin&utm_medium=social&utm_campaign=free_readiness_pack&utm_content=sme_owner
```

## LinkedIn → Avocați (recrutare parteneri)
```
https://eu-ai-act.ro/?utm_source=linkedin&utm_medium=social&utm_campaign=lawyers_campaign&utm_content=lawyer
```

---

**Regulă simplă:** dacă adaugi o campanie sau un public nou, adaugă-l mai întâi în `campaigns.json` / `audiences.json`, apoi construiește linkul — așa rămân toate consistente și ușor de filtrat mai târziu în analytics.
